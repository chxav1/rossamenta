# Rossamenta · web

Web de Rossamenta (Cakes & Cookies, Tarragona). Se publica en Vercel; las fotos, el vídeo, el CSS y el JS se sirven desde este repo vía jsDelivr.

- `assets/` fotos, logo y vídeo
- `css/`, `js/` estilos, motor 3D de tartas (`cake.js`) y la app (`app.js`)
- `index.template.html` plantilla; `python3 build.py <URL_ASSETS> <URL_CODIGO> index.html`
